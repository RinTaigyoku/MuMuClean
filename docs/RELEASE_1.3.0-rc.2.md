# MuMu 清爽助手 1.3.0-rc.2

这次加了“按顺序退出 MuMu”。新版 MuMu 有时关闭会未响应，直接结束进程又不太放心，所以加一个通过官方管理接口退出的入口。

先关闭主实例，确认 Android 已停止，再退出管理器。检测到 MAA 正在运行会提示先结束任务并退出 MAA；有其他多开实例也会停下来。等不到正常退出就保留进程，不强杀虚拟机。

顺序退出已实机成功测试一次，Android 和管理器都正常退出，CEF 子进程也退出了。原生关闭按钮卡住这次没有复现，目前只是绕行办法，还不能说修好了 MuMu 自己的退出问题。

前一测试版的广告规则和可恢复帧率设置继续保留，相关验证范围不变。配置和日志仍只保留本机，发布包不含测试电脑的数据。
