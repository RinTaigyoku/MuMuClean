# MuMu 清爽助手 1.3.0-rc.1

MuMu 又多了启动推广和桌面弹窗，这次补两处处理，也加了一个省占用按钮。

商店悬浮窗权限会先记下原始状态，再做限制；启动推广索引先备份，再清空并设为只读。这两项都能恢复，也都不需要重启 ADB。商店安装服务和系统安装器继续保留。

省占用按钮把主实例帧率上限设到 30 FPS，原来更低的保持原值。画面流畅度会下降，实际能省多少看游戏和机器。想改回去点“恢复原始帧率”。广告恢复和帧率恢复是两个独立操作。

已经验证了权限来回恢复、启动索引原样恢复、30/60 FPS 官方接口读写，以及规则生效后的安装会话创建和撤销。MAA 保持运行，ADB 还是普通 Shell。

这次先按测试版发。启动和弹窗的完整触发周期、真实 APK/XAPK 安装、MAA 完整作战任务还没测完，不能把安装会话测试当作实际安装成功。只读索引也可能被 MuMu 替换或更新，不能保证以后所有版本永久无广告。这个功能也不是整机卡死修复工具。

程序没有上传功能，配置和恢复记录只保存在本机。仓库与发布包不包含测试电脑的配置、日志和设备标识。
