# MuMu 清爽助手 1.5.0

这次专门适配 5.30.2 / Android 12。老版本用着流畅，就继续用，不用为了广告和更新提示来回折腾。原来的 6.8.9 / Android 15 分支也保留。

- 补上 Android 12 的精确应用身份过滤，旧商店按实际存在的广告组件处理，保留原桌面。
- 保留 APK/XAPK 安装和 OBB 数据。App 覆盖更新、游戏资源下载继续走原来的链路。
- 新增“Root 与更新”：5.30.2 可选一键配置 KitsuneMagisk 31024、Zygisk 和 Vector 2.0，保存原始设置，支持回退。去广告不需要开启它。
- 新增关闭 MuMu 自身版本更新提示，处理“发现新版本／重启更新”，支持恢复原更新器。用户 App 和游戏的更新继续保留。
- 旧版与新版恢复记录分开，去广告、帧率、Root、MuMu 更新各自撤销。
- 管理命令统一超时与串行执行，启动助手按窗口事件工作，没有新增 Android 常驻代理。

MAA 连接、增强截图与触控，APK/XAPK 和 OBB、App 覆盖更新及数据保留、资源下载、Root 安装与回退完成样例检查。Android 15 这轮保留原分支，历史实机记录仍在仓库，不冒充本轮重测。

Root 是额外功能，上游 Kitsune 分支标记为实验性，部分 App 会检测 Root。配置和回退会重启主实例，先结束当前任务。具体范围、第三方版本和限制见仓库说明。

下载 **MuMuClean.exe** 即可，启动助手已内嵌。旧版用户保持 Android 开着，运行新版重新点一次“全面去除广告”。想撤销就点对应恢复按钮。

后续厂商更换广告链路时仍可能需要更新规则，不拿“永久有效”当保证。发布文件不含本机日志、截图、恢复点、设备信息、测试应用或 MuMu 安装文件。
