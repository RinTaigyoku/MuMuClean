# MuMu 清爽助手 1.1.0

这版是第一次公开发布，已经按 MuMuPlayer 国际版 6.8.0.0 的实际安装环境检查过。

## 能做什么

- 处理启动界面的推广内容。
- 去掉 Android 桌面的广告横幅和游戏推荐来源。
- 随时一键恢复，不用重装模拟器。
- 不常驻后台，不安装服务。

## 不会动什么

- 不动游戏数据和虚拟机磁盘。
- 不改 CPU、内存、显卡和性能设置。
- 不拦游戏网络、MuMu 主程序和官方更新器。
- 不修改或替换 MuMu 的 EXE、DLL、APK 文件。

## 使用方法

先把 MuMuPlayer 启动到桌面，再以管理员身份打开 `MuMu清爽助手.exe`，点击“全面去除广告”。完成后重启一次模拟器。

想恢复时保持模拟器正在运行，打开工具点击“全面恢复”即可。

## 已知情况

- 当前验证版本为 MuMuPlayer 国际版 6.8.0.0。
- 大版本更新如果改了组件路径，旧规则可能需要重新适配。
- 本工具处理的是 MuMu 自带推广，不负责游戏或其他 App 内部广告。
- 未对程序做商业代码签名，Windows 可能显示“未知发布者”。

SHA-256 会和 EXE 一起放在 Release 附件中，下载后可以自行核对。
