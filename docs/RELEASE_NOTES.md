# MuMu 清爽助手 1.4.0

这次把旧规则漏掉的进桌面弹窗补上了。保留 MuMu 原桌面，配置好以后正常启动 Android 就行，不用再开一个页面，更不用两个桌面来回切。

- 处理启动推广、桌面广告横幅、游戏推荐和已确认的桌面弹窗链路。
- root 开着、关着都兼容，不需要用户开启 root，也不重启 ADB。
- 广告网络规则只针对原桌面和商店的应用身份，不按共享 IP 封服务器，不改全局 DNS、hosts 或 VPN。
- 保留商店、系统安装器和 APK/XAPK 安装服务，广告组件按原始状态备份，支持全面恢复。
- 增加 Windows 启动助手，启动时自动补上规则。主窗口可以退出，助手不轮询游戏、不处理画面，恢复时一起移除。
- 去掉额外 Android 桌面和隔离页面，正式包不再包含 Android 隔离 APK。
- 规则修改增加跨进程互斥和写入后校验，防止主程序与启动助手同时操作；恢复失败会保留恢复记录。
- MAA 的连接、增强截图与触控接口继续保留，用户 App 的安装、覆盖更新和资源下载已做样例复查。

当前针对 MuMuPlayer 国际版 6.8.9.0 / Android 15 检查。MAA 完整作战任务和所有第三方 App 没有逐一跑完，具体检查范围看仓库的检查记录。后续 MuMu 改广告链路时会继续跟进规则，不拿“永久有效”当保证。

下载 `MuMuClean.exe` 即可，启动助手已内嵌。旧版用户保持 Android 开着，运行新版重新点一次“全面去除广告”。想撤销就点“全面恢复”。
