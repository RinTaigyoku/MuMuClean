# MuMu 清爽助手 1.1.1

这次主要修一个会影响正常使用的问题：旧版为了去掉桌面推荐，把整个 MuMu 商店系统包停用了。这个包同时参与 APK/XAPK 安装，所以部分情况下会出现软件装不上的问题。

1.1.1 已经改掉这套处理方式。

## 修复内容

1. 不再停用整个 `com.mumu.store`。
2. MuMu 商店和 Android 系统安装器始终保持启用。
3. 只停用广告横幅、每日推荐和两个跟踪组件。
4. 处理组件时临时使用 ADB root，完成以后立即恢复普通 Shell 权限。
5. 运行新版并点击“全面去除广告”，会自动修复旧版留下的商店停用状态。
6. 程序图标换成了透明背景的猫咪图标。

## 怎么更新

直接下载新版覆盖旧版即可。先启动 MuMuPlayer，等 Android 桌面出现，再运行 1.1.1 点击一次“全面去除广告”。

如果之前已经遇到无法安装软件，新版执行完成后重新尝试安装，不需要重装模拟器。

## 仍然不会修改的东西

- 游戏数据和虚拟机磁盘。
- CPU、内存、显卡和渲染设置。
- MuMu 的 EXE、DLL 和 APK 文件。
- 游戏网络、MuMu 主程序和官方更新器。

当前验证环境：MuMuPlayer 国际版 6.8.5.0、Android 15；同时兼容之前测试的 6.8.0.0。
