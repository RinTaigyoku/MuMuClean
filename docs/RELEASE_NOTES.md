# MuMu 清爽助手 1.1.0

这是第一次公开发出来的版本，目前已经按我自己电脑上的 MuMuPlayer 国际版 6.8.0.0 检查过。

我做这个工具的要求很简单：广告要尽量清干净，但是不能为了去广告把模拟器性能、游戏网络和以后更新一起搞坏。万一不喜欢，还必须可以完整恢复。

## 这版做了什么

1. 处理启动界面的推广内容。
2. 去掉 Android 桌面的广告横幅和游戏推荐来源。
3. 增加“全面恢复”，不需要重装模拟器。
4. 不驻留后台，不安装服务，不自动启动。
5. 保留 MuMu 主程序、游戏网络和官方更新器的正常联网。

## 不会修改的东西

- 游戏数据和虚拟机磁盘。
- CPU、内存、显卡和渲染设置。
- MuMu 的 EXE、DLL 和 APK 文件。
- Windows 电源计划和系统性能设置。

## 怎么用

先把 MuMuPlayer 启动到桌面，再以管理员身份打开 `MuMu清爽助手.exe`，点击“全面去除广告”。完成以后重启一次模拟器。

要恢复的时候保持模拟器正在运行，点击“全面恢复”。

## 下载前说明

- 当前验证版本：MuMuPlayer 国际版 6.8.0.0。
- 这个工具只处理 MuMu 自带推广，不管游戏和其他 App 内部的广告。
- 程序没有商业代码签名，Windows 可能显示“未知发布者”。
- 大版本更新如果换了路径或者组件名，需要重新适配。

附件里有 SHA-256 校验文件，下载以后可以自己核对。
