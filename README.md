# MuMu 清爽助手

<img src="assets/icon-transparent.png" width="128" alt="MuMu 清爽助手图标">

MuMu 国际版广告又冒出来了，旧规则确实有漏的。这次把启动推广、桌面横幅、游戏推荐和进桌面弹窗一起处理了，顺便把之前折腾的额外桌面和隔离页面撤掉。

**配置一次，以后正常启动 Android，直接用原来的桌面。不用两个桌面来回切，也不用每次打开工具。**

当前正式版：**1.4.0**。下载看 [Releases](https://github.com/RinTaigyoku/MuMuClean/releases/latest)，选 `MuMu清爽助手.exe` 就行，启动助手已经打包在里面。

## 怎么用

1. 启动 MuMuPlayer 国际版，等 Android 进入桌面。
2. 打开清爽助手，同意 Windows 管理员权限。
3. 点“全面去除广告”，等日志提示规则已应用。
4. 重启一次模拟器，之后正常用就行。

想恢复就保持 Android 开着，点“全面恢复”。恢复点会保留到恢复成功，不用重装模拟器。第一次应用前的组件状态、悬浮窗权限、启动索引和文件属性都会保存；恢复时移除本工具的网络规则、启动助手和自启动项。帧率有独立的恢复按钮。

## 这次具体改了什么

- 保留 MuMu 原桌面，处理启动推广、桌面推荐和已确认的进桌面弹窗链路。
- 关闭四个推荐、广告追踪组件，保留商店、安装服务和系统安装器。
- 通过 MuMu 官方管理工具添加 Android 网络规则，只针对原桌面和商店的应用身份，匹配已确认的推广配置域名。IPv4、IPv6 都处理，不按整个服务器 IP 一刀切。
- 不改全局 hosts、DNS、VPN、默认桌面，不修改模拟器的 EXE、DLL、APK 或虚拟机镜像。
- root 开着、关着都能用。无需开启 root，也不执行 `adb root/unroot`。
- 不重启 ADB server，不断开 MAA 的设备连接，不改 MAA 的设置。

不是拿“广告组件关了”就当全面完成。检测会读取当前网络规则、组件状态、悬浮窗权限和启动索引，没生效会明确提示。

## 后台占用

配置完成后主窗口可以退出。会留下一个 Windows 启动助手，这是为了让免 root 环境重启 Android 后也能自动补上规则。

助手通过窗口事件识别模拟器启动，只处理登记过的实例，并核对实例创建标记，避免误操作后来新建的同序号实例。启动阶段有限重试，完成以后不轮询进程、不处理游戏画面、不代理游戏流量。点全面恢复会一起移除。

“省占用（30 FPS）”是单独的可选功能。它只降低主实例帧率上限，会降低流畅度，不默认开启，也不乱改 CPU、内存、显存和驱动。想恢复点“恢复原始帧率”。

## MAA、安装和更新

保留 APK/XAPK 安装链路。网络规则只落在原桌面和商店对应的 UID 上，普通用户 App 不在名单里，后续新装的 App 也不会被自动拉进来。

发布复查覆盖了组件与网络规则的应用/恢复、root 开关关闭时的管理通道、APK 安装、XAPK 和 OBB 落盘、同签名 App 覆盖更新、数据保留、HTTPS 资源下载，以及 MAA 连接、增强截图和触控接口。详细结果见 [检查记录](docs/VALIDATION_1.4.0.md) 和 [MAA 说明](docs/MAA.md)。

当前核查版本是 MuMuPlayer 国际版 6.8.9.0 / Android 15。没有把普通框架热更新直接判成广告热更新，更不会为了去广告删掉核心更新逻辑。工具处理已确认的广告链路，MuMu 后续改域名、组件或协议时仍可能需要更新规则。

本工具不负责去除用户自行安装的游戏或 App 内的广告，也不伪造会员状态。商店悬浮窗限制会同时限制商店自己的其他悬浮展示；已确认的推广配置域名包含桌面推荐配置，相关在线推荐会一起停用。

## 自己编译

Windows 自带的 .NET Framework 4.x 编译器即可，PowerShell 运行：

```powershell
.\build.ps1
```

输出在 `dist`。主 EXE 内嵌启动助手，不需要 Android SDK 或第三方安装包。恢复点和机器路径只留在使用者本机，程序没有遥测，不上传配置、日志或游戏数据。

本项目与 MuMuPlayer、网易及 MAA 官方无关。
