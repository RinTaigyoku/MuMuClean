# MuMu 清爽助手

<img src="assets/icon-transparent.png" width="128" alt="MuMu 清爽助手图标">

MuMu 广告反复冒出来，旧规则有漏的就继续补。这次专门适配 **5.30.2 / Android 12**，之前的 **6.8.9 / Android 15** 也继续保留。

**配置一次，以后正常启动 Android，直接用原来的无广告桌面。不用两个桌面来回切，也不用每次打开工具。**

当前正式版：**1.5.0**。到 [Releases](https://github.com/RinTaigyoku/MuMuClean/releases/latest) 下载 `MuMuClean.exe`，启动助手已经打包在里面。

## 怎么用

1. 启动 MuMuPlayer 国际版，等 Android 进入桌面。
2. 打开清爽助手，同意 Windows 管理员权限。
3. 点“全面去除广告”，等日志提示规则已应用。
4. 重启一次 Android，之后正常用就行。

想恢复就保持 Android 开着，点“恢复去广告”。恢复点会留到恢复成功。原来的组件状态、商店悬浮窗权限、启动广告索引和文件属性都会保存；恢复时移除本工具的网络规则、启动助手和自启动项。

去广告、帧率、Root 环境、MuMu 版本更新是四个独立开关，各自恢复，不会点一次恢复就把其他设置也撤了。

## 广告怎么处理

- 处理已确认的启动推广、桌面横幅、游戏推荐和进桌面弹窗链路，保留 MuMu 原桌面。
- 按当前商店实际存在的组件停用推荐和追踪入口，保留商店、系统安装器、APK/XAPK 安装服务与安装广播。旧商店只有两个对应组件时，不再拿新版四组件清单硬套。
- 推广网络规则只选择原桌面和商店对应的 UID，匹配已确认的推广配置域名。IPv4、IPv6 都处理，不按整个服务器 IP 封禁。
- Android 12 的内核缺少原来的 UID 匹配模块，这次补了独立实现；Android 15 继续走原来的分支。
- 不改全局 hosts、DNS、VPN、默认桌面，不代理游戏流量。去广告本身不修改模拟器的 EXE、DLL、APK 或系统盘。
- 去广告兼容 MuMu 自带 Root 开关开启和关闭的环境，不需要安装 Magisk 或 Vector，也不执行 `adb root/unroot`。

这里的清理是停用已经确认的广告、推荐和追踪路径，没有把不认识的代码全删掉。核心系统服务、安装服务、游戏资源更新都保留。检查会读实际规则，没生效会提示，不拿一份配置记录就算完成。

## 5.30.2 一键配置 Root

打开“Root 与更新”，点“一键配置 Root”。仅支持 5.30.2 / Android 12 的主实例，与去广告分开，默认不安装。

本轮选用 **KitsuneMagisk 31024 + 内置 Zygisk + Vector 2.0（3021）**。首次从各自 GitHub 上游下载固定版本，核对 SHA-256 后才修改模拟器。下载失败不会改 Root 开关。已有第三方 Root 或 Vector 环境会拒绝覆盖。

配置会保存原始 Root 和系统盘开关，按上游事务安装方式配置并重启 Android。框架接管后关闭 MuMu 自带 Root，避免两个实现重复运行。这个 System Mode 需要系统盘保持可写；点“回退 Root 环境”会还原系统文件及原来的两个开关，移除本工具安装的管理器，保留其他模块配置数据。

**Root 是额外功能。** 上游这条 Kitsune 分支标记为实验性；这里固定的是本轮跑通安装、启动和回退的组合，不能保证适合所有模块。部分 App 会检测 Root，遇到这种情况可以回退；不要为了去广告开启它。不预装其他 Hook 模块，不给所有 App 批量授予 Root。配置和回退会重启主实例，先结束正在进行的任务。

版本、校验值和上游源码见 [第三方说明](docs/THIRD_PARTY.md)。

## 关闭 MuMu 版本更新提示

“Root 与更新”里的“关闭 MuMu 更新”，针对的是 **MuMu 自身的版本更新提示**，包括“发现新版本／重启更新”。保留独立更新器原文件和校验记录，停用后重新打开“关于 MuMu”即可复查；当前会话仍缓存旧提示时，重开管理器。

想更新模拟器，先点“恢复 MuMu 更新”。恢复会校验原文件，不覆盖厂商后来换上的不同版本。

**这不是关闭游戏更新。** 用户安装的 App、APK/XAPK 安装、应用覆盖更新和游戏资源热更新不在这个开关范围内。去广告也不会默认关闭模拟器更新；是否锁定老版本由自己选。

## MAA、安装和性能

不重启 ADB server，不断开设备连接，不改 MAA 配置。明日方舟和普通用户 App 不在广告过滤名单里，后续新装的 App 也不会自动加入。

Android 12 本轮检查包含：去广告应用与恢复、Root 开关关闭、可选 Root 框架安装与回退、APK/XAPK 和 OBB 安装、同签名覆盖更新与数据保留、App 内 HTTPS 资源下载、MAA 连接、截图和触控。主实例与免 Root 测试实例的 MuMu 增强截图均已跑通。具体范围见 [1.5.0 检查记录](docs/VALIDATION_1.5.0.md) 和 [MAA 说明](docs/MAA.md)。

Windows 启动助手通过窗口事件识别登记过的实例，启动阶段有限重试，完成以后不轮询游戏、不处理画面。Android 12 的身份过滤在内核中完成，没有新增 Android 常驻代理。主窗口用完可以退出。

“省占用（30 FPS）”仍是单独的可选功能，会降低流畅度；默认不开启，不乱改 CPU、内存、显存和驱动。Root 框架本身会增加服务和注入开销，不属于去广告的性能承诺。

没有穷举所有游戏、所有 MAA 任务或未来 MuMu 版本。后续厂商更换广告域名、组件或协议时，规则仍可能需要更新。本工具不处理用户自行安装的游戏或 App 内广告，也不伪造 MuMu 会员状态。

## 自己编译

Windows 自带 .NET Framework 4.x 编译器，PowerShell 运行：

```powershell
.\build.ps1
```

输出在 `dist`。主 EXE 内嵌启动助手和小型 Android 12 身份过滤加载器；只有选择 Root 功能时才下载第三方安装包。加载器源码和构建命令见 [native/README.md](native/README.md)。

恢复点和运行组件放在本机 `%ProgramData%\MuMuAdCleaner`；停用的 MuMu 更新器备份留在原安装目录。不要删除这些恢复数据。程序没有遥测，不上传配置、路径、日志、设备标识或游戏数据。

本项目与 MuMuPlayer、网易及 MAA 官方无关。
