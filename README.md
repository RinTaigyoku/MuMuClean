# MuMu 清爽助手

<img src="assets/icon-transparent.png" width="128" alt="MuMu 清爽助手图标">

我用的是 MuMuPlayer 国际版，启动的时候有推广，进入桌面以后左边还有广告横幅和游戏推荐。看着不舒服是一方面，另一方面我也不想为了去几个广告就乱改模拟器文件，最后搞得更新不了或者性能出问题。

所以我做了这个小工具。

> **1.3.0-rc.1 测试版**：补上商店悬浮窗权限限制和启动广告缓存索引处理，新增可恢复的主实例 30 FPS 模式。基础状态和恢复测试已通过，重启后的广告展示、实际 APK/XAPK 安装与 MAA 完整任务仍需验证。先按测试版发布，有问题可以恢复。

新版新增的两处处理均不需要重启 ADB。启动索引先备份，再清空并设为只读，减少旧推广继续加载；普通只读属性可能被 MuMu 替换文件或官方更新绕过，因此不能承诺永久无广告。商店悬浮窗限制也会影响商店自身的其他悬浮展示。

“省占用（30 FPS）”只调整主实例帧率上限，降低流畅度来减少渲染负担，不代表每台电脑都能明显省资源。不改 CPU、内存、显存策略、驱动、应用保活和 MAA 设置。“恢复原始帧率”是独立按钮，全面恢复广告规则不会自动改变帧率。

目前已经在 MuMuPlayer 国际版 6.8.0.0 和 6.8.5.0 实机检查，默认支持 `E:\MuMuPlayerGlobal`，其他位置会尝试从注册表自动寻找。

> 1.2.0 增加 MAA 安全保护。检测到 MAA 正在运行时，不会切换 ADB root、不会杀掉 ADB server，也不会刷新桌面；已经处理过的实例只做状态核对，尚未处理的 Android 组件会等退出 MAA 后再补齐。

## 这个程序能做什么

1. 去掉 MuMu 自己带的推广网页、桌面广告横幅和游戏推荐来源。
2. 不修改 MuMu 的 EXE、DLL、APK 和虚拟机镜像。
3. 不拦游戏网络，不动 CPU、内存、显卡和其他性能设置。
4. 不影响 `MuMuNxUpdater.exe`，以后照常检查和安装官方更新。
5. 随时可以点“全面恢复”，不用重装模拟器。
6. 处理完成以后直接退出就行，不驻留后台，不装服务，也没有遥测。
7. 专门兼容 MAA，优先复用 MuMu 的 `nx_main\adb.exe` 和官方实例端口，不额外制造重复设备连接。

## 会不会影响性能和启动速度

去广告规则保留游戏渲染与安装链路。30 FPS 模式会降低游戏流畅度，实际资源收益和 MAA 任务耗时需要按使用环境检查。

Windows 端只有两条按完整程序路径匹配的规则，目标是 MuMu 自带的两个 CEF 推广页面进程。主程序、虚拟机、渲染器、ADB、游戏网络和更新器都不在规则里。

Android 端只停用 MuMu 商店里的四个广告组件，商店包、系统安装器、XAPK 安装入口和本地安装服务保持启用。只有在 MAA 未运行并且确实需要修改组件时，才会短暂切换 ADB root，完成以后立即恢复普通 Shell 权限，不会留下后台 root 进程。

程序本身没有后台进程。点完“全面去除广告”以后关掉工具，不会一直扫描，也不会每次开机自启。

## 使用方法

1. 先启动 MuMuPlayer，等它进入 Android 桌面。
2. 右键运行 `MuMu清爽助手.exe`，同意管理员权限。
3. 点击“全面去除广告”。
4. 等提示完成以后重启一次 MuMuPlayer。

如果以后想恢复，保持模拟器正在运行，打开工具点击“全面恢复”即可。

如果 MuMu 更新以后广告又出现，再运行一次“全面去除广告”。大版本如果改了组件名称，我会再更新规则。

## MAA 适配

这版按 MAA 的连接方式做了实机适配，处理原则很简单：尽量复用 MuMu 自带的 ADB 和当前已经在线的实例，不去抢 MAA 正在用的连接。

- 优先使用 `nx_main\adb.exe`
- 优先识别 `127.0.0.1:16384` 开始的 MuMu 官方实例端口
- 兼容 MAA 的 `MuMuEmulator12` 连接配置
- 不修改 MAA 的设置、任务和日志
- 不干扰 MuMu 增强截图与增强触控

工具发现 MAA 正在运行时会自动进入保护模式。Windows 端的广告规则照常处理；如果四个 Android 广告组件还没关闭，会明确提示退出 MAA 后再点一次，不会为了去广告把正在工作的 MAA 连接掐断。

详细检查项目和推荐设置见 [MAA 兼容说明](docs/MAA.md)。

## 我没有做的事情

- 不负责屏蔽你安装的游戏或者其他 App 里面的广告。
- 不伪造会员状态，不破解付费功能。
- 不修改 MuMu 的签名文件。
- 不上传任何配置、路径和日志。

界面里如果只是会员功能本身的文字或者入口，不保证所有版本都能隐藏。本工具主要处理实际加载的推广内容和桌面推荐位。

## 自己编译

系统需要 Windows 自带的 .NET Framework 4.x 编译器。用 PowerShell 运行：

```powershell
.\build.ps1
```

生成的 EXE 在 `dist` 文件夹。

## 其他说明

程序需要管理员权限，是因为 Windows 防火墙规则的创建和删除必须提权。源码很短，担心的话可以直接看完再自己编译。

本项目与网易、MuMuPlayer 官方没有关系。使用前请自己确认当地法律和软件服务条款。
