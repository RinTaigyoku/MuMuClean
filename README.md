# MuMu 清爽助手

当前已验证 MuMuPlayer 国际版 6.8.0.0，默认识别 `E:\MuMuPlayerGlobal` 和注册表安装路径。

这个工具只处理 MuMuPlayer 国际版自己带的推广内容，主要是启动界面的推广入口、桌面横幅和游戏推荐位。它不会碰你安装的游戏，也不会拦游戏里的广告。

## 功能

- 全面去除广告：隔离 Windows 广告 WebView 的联网能力，并停用 Android 侧 MuMu 商店广告组件与推荐源。
- 全面恢复：只撤销本程序创建的规则，并恢复 Android 组件的原始状态。
- 保持更新：不拦截主程序、游戏网络或 `MuMuNxUpdater.exe`，不修改安装文件、虚拟机镜像、游戏数据及性能设置。
- 低开销：应用规则后程序可直接退出，不驻留后台、不安装服务。

## 对性能有没有影响

应用完成后程序不会留在后台。Windows 端只有两条按程序路径匹配的出站规则，目标是 MuMu 自带的两个 CEF 推广页面进程；虚拟机、渲染器、ADB、游戏网络和更新器都不在规则里。Android 端停用的是 MuMu 商店推广源，正常情况下还会减少一点后台占用。

不会修改 CPU 核心数、内存、显卡渲染模式、磁盘镜像或电源计划。按当前 6.8.0.0 的进程结构，不会影响游戏帧率和模拟器启动流程。

## 使用

1. 启动 MuMuPlayer，使 Android 实例进入桌面。
2. 右键 `dist\MuMu清爽助手.exe`，选择“以管理员身份运行”（程序也会自动请求管理员权限）。
3. 点击“全面去除广告”，完成后重启 MuMuPlayer。
4. 如需撤销，保持 MuMuPlayer 正在运行，点击“全面恢复”。

若更新后广告重新出现，再运行一次“全面去除广告”即可。恢复点保存在 `C:\ProgramData\MuMuAdCleaner\state.ini`。

## 边界

程序针对 MuMu 自身推广位，不会拦截用户安装的游戏或应用内广告。若 MuMu 后续大版本更换组件名称，需要更新规则。

工具不会伪造会员状态，也不会修改 MuMu 的签名程序文件。界面里属于会员功能本身的文字或入口，不保证在所有版本中都能隐藏。

本项目与网易、MuMuPlayer 官方无关。使用前请自行确认当地法律及软件服务条款。
